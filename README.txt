CODE CANVAS ONE-PAGE WEBSITE

Files:
- index.html: complete responsive one-page website. No build tools or paid services required.

PUBLISH FREE WITH GITHUB PAGES:
1. Sign in to https://github.com/ and create a new public repository named code-canvas.
2. Upload index.html (and this README if desired) to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish. Your URL will look like:
   https://YOUR-GITHUB-USERNAME.github.io/code-canvas/
7. Open the published URL and check it loads before entering it into any business onboarding form.

You can edit the email, business description, services and links directly in index.html.

Note: A public GitHub Pages URL is a hosting URL, not proof of business ownership or Meta verification. Use it only where a website/profile URL is requested and accurately describe your business.
